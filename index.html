手机安装：中转页卡住时用这个

安卓浏览器点直链后，若停在篡改猴的 SCRIPT INSTALLATION 中转页不跳转， 改用粘贴安装，成功率最高。
打开纯文本版
  1. 点 复制脚本全部代码（或打开纯文本版后全选复制）。
  2. 篡改猴图标 → 管理面板 → ＋ 添加新脚本。
  3. 把编辑器里的模板 全部删除，粘贴刚复制的代码。
  4. 点 保存（软盘图标 / Ctrl+S）。列表里出现「问卷星 Demo 快速填充」即成功。
  5. 手机访问问卷页时建议开启浏览器的 电脑版网页 / 请求桌面站点。

安装步骤

  1. 浏览器安装 篡改猴（Tampermonkey） 扩展并启用。
  2. 点上方 一键安装到篡改猴，在弹出页点 安装。
  3. 若之前装过旧版：先在篡改猴管理面板 删除所有旧的同名条目，只保留这一份。
  4. 打开问卷页，右下角出现面板即生效；面板左下角应显示 v0.27.0。
  5. 首次使用点 填写配置信息，填好固定答案并 保存固定答案（仅存本机）。

功能说明

  • 到点自动进入：与页面倒计时同步，归零后约 30 毫秒点击开始按钮，点击被拒时每 250ms 重试。
  • 按配置填写：学号 / 姓名 / 性别 / 手机 / 校区 / 本科生·研究生 / 学院 / 专业 / 班级 / 宿舍 / 身份证号，支持相似标签与简称选项模糊匹配。
  • 自定义题目规则：配置区「自定义题目」按「题目关键词 → 答案」自动作答单选、多选、下拉与填空，多选用 | 分隔。
  • 选择题自己选：没命中规则的题目会在面板「待选题目」里列出，点一下就选上；开启「记住」后自动存成规则，下次全自动。
  • 填空兜底：可设一句兜底文本（如「无」），未匹配的填空题自动填它；留空则保持不填。
  • 缺项留空：配置里没有的字段一律留空，绝不随机编造。
  • 新字段保护：出现无法对应的新字段时只勾选同意、不自动提交。
  • 提交可选：面板常驻「勾选同意并提交」开关，每页仅提交一次。
  • 逐字段随机延时：默认 30–300ms，可在配置区修改。
  • 诊断日志：配置区「复制诊断」可导出带时间戳的执行记录，便于排查。

没有弹出安装页？

  1. 确认篡改猴已启用：扩展图标 → 管理面板 → 右上角开关为开启。
  2. 篡改猴设置 → 通用 → 配置模式改为 初学者 或 高级，并允许 .user.js 安装。
  3. 若浏览器把 .user.js 当文件下载了：把下载到的文件拖进篡改猴管理面板，或改用上方「复制脚本全部代码」粘贴安装。
  4. 也可复制上方链接，在篡改猴管理面板 → 实用工具 → 从 URL 安装 粘贴安装。
