# Auto-fill · 问卷星 Demo 快速填充

一个 Tampermonkey 用户脚本：**倒计时归零后约 30 毫秒自动点击开始**，随后按本机保存的固定配置自动填写问卷。

> 仅用于**自有或已获授权**的问卷星 demo 测试。不绕过安全校验、验证码、登录或风控；触发安全校验时停下并提示人工完成。

## 一键安装

**直链安装**（已装篡改猴时点击即弹出安装确认）：
https://raw.githubusercontent.com/Guzifeng0613/Auto-fill/main/wjx-demo-fastfill.user.js

**网页版安装页**：仓库内 `index.html`，可直接下载打开；若开启 GitHub Pages，则可通过
https://guzifeng0613.github.io/Auto-fill/ 访问。

> 开启 Pages 只需一次：仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
> 之后每次推送到 `main`，`.github/workflows/pages.yml` 会自动部署安装页。

安装前请先装好 [Tampermonkey](https://www.tampermonkey.net/)。若装过旧版本，请在篡改猴管理面板中**删除所有旧的同名条目**，只保留一份，避免旧版抢先运行。

脚本已配置 `@downloadURL` / `@updateURL`，后续可在篡改猴中检查更新。

## 功能

- **到点自动进入**：与页面倒计时同步；归零后 30ms 点击开始按钮；点击被服务端拒绝时每 250ms 重试；必要时刷新兜底。
- **按配置填写**：学号、姓名、性别、手机号、学院、专业、班级、宿舍号、房间号、身份证号。
- **模糊匹配**：相似标签（学生证号 / 学工号 / 所在班级 / 所学专业 / 院系名称 / 证件号码等）与简称选项（计科 → 计算机、信工 → 信息工程等）均可识别。
- **缺项留空**：配置中没有的字段一律留空，不随机编造。
- **新字段保护**：出现无法对应的新字段时，只勾选同意、不自动提交。
- **提交可选**：面板常驻「勾选同意并提交」开关，每页仅提交一次。
- **逐字段随机延时**：默认 30–300ms，可在配置区调整。
- **诊断日志**：配置区「复制诊断」导出带时间戳的执行记录（启动 / 等待 / 点击 / 进入 / 刷新 / 停止）。

## 使用

1. 打开问卷页，右下角出现浮动面板。
2. 点「填写配置信息」，填好固定答案 → 「保存固定答案」（仅保存在本机浏览器）。
3. 倒计时页面会自动开启等待；归零后自动点击开始并填写。
4. 需要提交时勾选「勾选同意并提交」。
